# Contributing to LBR

LBR is currently a solo student-led project. Opening an issue or pull request does not make someone a company member, co-founder, employee, or representative of LBR.

Future contributions should be focused, tested, accessible to beginners, and submitted under the repository license. Hardware-data changes should include a source or verification note. Never commit secrets, generated output, local logs, personal data, or code you do not have permission to share.

Before proposing a change, run:

```bash
npm install
npm run check
npm run build
```
